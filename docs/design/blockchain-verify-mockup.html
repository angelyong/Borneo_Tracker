Data Verification

把 E（我们宣称资料没被改过）变成 B（任何人自己算得出来）。 下面是两个界面：每一页角落的小徽章，和点进去之后的验证页。

徽章状态

为什么四态都要有：会红的徽章才是真徽章。ODSF 那个站的 API 回传 status:"error"， UI 照样显示绿色 —— 那就变成装饰。我们的必须真的会变。

色彩只是辅助，状态一律用文字写出来 —— 这跟 DataFreshness.jsx 的既有规则一致，不依赖颜色传达资讯。

✓ 这证明什么

这些档案的内容自 2026-07-28 起没有被任何人修改过 —— 包括我们自己。

你不需要相信这句话。往下复制那两行指令，在你自己的电脑上算一次。

✕ 这不证明什么

这不代表数据是对的。如果原始来源本身有误，我们只是把那个错误也一并保存了下来。

资料品质另有标注 —— 请看每一列的 confidence 与 source，以及方法学说明。
